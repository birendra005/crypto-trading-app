# 🪙 Crypto Trading App

A  crypto trading application interface built with **React**, **TypeScript**, **Vite**, **CSS**,**Zustand** and **React Query**.
This app allows users to browse crypto assets, simulate trades between crypto and fiat (USD), and manage basic authentication locally.

---

### 🚀 Live Demo:
https://birendra005.github.io/crypto-trading-app

---

## ✨ Features

- 🔐 Local login system (no backend)
- 🛡️ Protected Trade route (login required)
- 📈 Real-time crypto prices (via CoinGecko API)
- 🔄 Two-way conversion between crypto & USD
- ↔️ Swap input directions
- 📊 Sortable, expandable crypto asset table
- ⚛️ Powered by Zustand & React Query
---

Tech Stack
⚛️ React + TypeScript
⚡ Vite
⚙️ Zustand (authentication)
🔍 React Query (data fetching + caching)
🌐 CoinGecko API  and Localization
🎨 CSS

🔧 Setup & Run Locally
# 1. Clone the repo
git clone https://github.com/birendra005/crypto-trading-app.git
cd crypto-trading-app

# 2. Install dependencies
npm install

# 3. Run the dev server
npm run dev
Visit http://localhost:5173 to view the app.
